# optimal-portfolio

**Objective** 
Find *the* portfolio that provides a good balance of performance across following features:
  - annual income
  - annual growth
  - high liquidity
  - low risk
  - low headache
  

**Methodology**
From a given list of investment tools, 
1/ generate all portfolios that will give an annual income between 5%-6% 
2/ score each portfolio on every feature -- weighted sum across investments for that feature
3/ give each portfolio an overall score by taking a weighted sum across all features 
4/ provides a table view that allows to sort on each feature, including the overall score
